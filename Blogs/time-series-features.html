Time-Series Models:
Feature Engineering

Muneeb Shafique
• Jan 05, 2026 • 12 MIN READ

Algorithms like XGBoost, LightGBM, and feed-forward neural networks do not inherently understand temporal dynamics. In time-series forecasting, predictive power lies in feature engineering—constructing representations that capture auto-correlation, seasonality, and trends.

01. Lag Features (Auto-Correlation)

LAG

Past Predicts Present

A lag feature shifts historical target values forward to serve as predictors for the current step. For example, to forecast tomorrow's stock price or product demand, today's price ($t-1$), yesterday's price ($t-2$), or the price from exactly one week ago ($t-7$) are critical features.

02. Rolling Window Statistics

While lag features capture specific historic points, rolling statistics capture smoothed historic behavior. Calculating rolling means, standard deviations, mins, and maxes over sliding windows (e.g., 7-day, 30-day) exposes shifting trends and volatility.

Pandas Lag & Rolling Window Setup
import pandas as pd

# Load your time-series data
df = pd.read_csv("demand_data.csv", parse_dates=["date"])
df = df.sort_values("date").set_index("date")

# Create lag features
for lag in [1, 2, 7]:
    df[f"demand_lag_{lag}"] = df["demand"].shift(lag)

# Create rolling window features
df["demand_roll_mean_7"] = df["demand"].shift(1).rolling(window=7).mean()
df["demand_roll_std_7"] = df["demand"].shift(1).rolling(window=7).std()
df["demand_roll_mean_30"] = df["demand"].shift(1).rolling(window=30).mean()

# Drop rows with NaN caused by shifting/rolling
df = df.dropna()

03. Calendar & Trigonometric Time Features

Extracting calendar indicators like day of the week, month, and hour helps models identify recurring seasonal variations. However, numerical representations (e.g. Month 12 to Month 1) create artificial discontinuities. We solve this by mapping calendar values to cyclical sine and cosine coordinates:

Cyclical Transformations
import numpy as np

# Map calendar month (1-12) to circular space
df["month_sin"] = np.sin(2 * np.pi * df.index.month / 12.0)
df["month_cos"] = np.cos(2 * np.pi * df.index.month / 12.0)

# Map day of week (0-6)
df["dayofweek_sin"] = np.sin(2 * np.pi * df.index.dayofweek / 7.0)
df["dayofweek_cos"] = np.cos(2 * np.pi * df.index.dayofweek / 7.0)
