Adversarial AI:
Attacks and Robust Defense

Muneeb Shafique
• Jan 18, 2026 • 14 MIN READ

Deep neural networks achieve superhuman performance in computer vision and natural language processing. However, they are highly vulnerable to adversarial attacks—subtle, mathematically optimized perturbations that cause models to make incorrect predictions with high confidence.

01. Understanding Adversarial Perturbations

SEC

Vulnerabilities in High Dimensions

Adversarial perturbations exploit the linear nature of neural networks in high-dimensional spaces. By making tiny changes in the direction of the cost function's gradient, an attacker can push an input vector across a decision boundary, tricking the classifier without altering human perception of the input.

02. White-Box Attack Algorithms: FGSM & PGD

In white-box scenarios where the attacker has full access to the model weights, they can compute gradients directly. The Fast Gradient Sign Method (FGSM) computes the gradient of the loss function with respect to the input data and alters the input by a step size $\epsilon$ in that direction. Projected Gradient Descent (PGD) iterates this process multiple times, representing one of the strongest first-order adversarial attacks.

PyTorch FGSM Perturbation
import torch
import torch.nn.functional as F

def fgsm_attack(image, epsilon, data_grad):
    # Collect the sign of the data gradient
    sign_data_grad = data_grad.sign()
    
    # Create the perturbed image by adjusting each pixel
    perturbed_image = image + epsilon * sign_data_grad
    
    # Clip values to maintain the valid [0, 1] range
    perturbed_image = torch.clamp(perturbed_image, 0, 1)
    
    return perturbed_image

# Calculating gradient during evaluation
def test_adversarial(model, device, test_loader, epsilon):
    model.eval()
    for data, target in test_loader:
        data, target = data.to(device), target.to(device)
        data.requires_grad = True
        
        output = model(data)
        loss = F.nll_loss(output, target)
        model.zero_grad()
        loss.backward()

        perturbed_data = fgsm_attack(data, epsilon, data_grad)

03. Mitigating Risks: Adversarial Training

Defending neural networks requires training them to expect adversarial inputs. The most effective defense is adversarial training—injecting adversarial examples (generated via PGD or FGSM during the training loop) directly into the training batches.

  • Adversarial Training Loop Generates mini-batch perturbations dynamically and updates model parameters to minimize loss on these perturbed inputs, expanding the model's decision boundaries.
  • Gradient Masking (Caveat) A common pitfall where defenses merely smooth the gradients, making it harder for gradient-based optimizers to find perturbations. Attackers easily bypass this using transfer attacks.
  • Model Compression & Pruning Simplifying network architecture and pruning redundant connections can improve general model generalization, which structurally increases resilience to random noise and minor perturbations.
